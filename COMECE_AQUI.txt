OI! VOCÊ TEM O SISTEMA COMPLETO AQUI.

NÃO SABE POR ONDE COMEÇAR? SIGA ESTES 4 PASSOS SIMPLES:

================================================================================
1️⃣  INSTALAR O BANCO DE DADOS (5 MINUTOS)
================================================================================

   Terminal/CMD:
   
   mysql -u root -p
   (digite sua senha)
   
   source database/schema.sql
   (e pronto!)

   OU use phpMyAdmin e importe o arquivo database/schema.sql

================================================================================
2️⃣  CONFIGURAR O SISTEMA (2 MINUTOS)
================================================================================

   Abra: config/config.php
   
   Mude estas linhas com SUA SENHA MYSQL:
   
   define('DB_USER', 'root');        ← seu usuário MySQL
   define('DB_PASS', '');            ← sua senha MySQL
   
   Salve o arquivo.

================================================================================
3️⃣  INICIAR O SERVIDOR (1 MINUTO)
================================================================================

   Terminal/CMD na pasta SISTEMA_OUVIDORIA_COMPLETO:
   
   php -S localhost:8000 -t public/
   
   Você verá:
   [Thu Apr 26 15:00:00 2026] PHP 7.4.0 Server running...

================================================================================
4️⃣  ABRIR NO NAVEGADOR (1 MINUTO)
================================================================================

   🏠 HOME (comece aqui):
   http://localhost:8000/home.html
   
   📝 Fazer Denúncia:
   http://localhost:8000
   
   🔍 Rastrear Denúncia:
   http://localhost:8000/rastrear.html
   
   📊 Dashboard:
   http://localhost:8000/dashboard.html
